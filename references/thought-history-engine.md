# 思想史定位引擎

## 适用范围

仅在对话者模式（阶段五）使用。对用户经先贤辩论后形成的最终论证进行深度结构分析。

## 触发条件

对话者模式阶段五开始时，用户已给出最终论证。

## 六维分析框架

### 维度一：核心论点提炼

用一句话还原用户论证的核心主张。

格式：
> 你的核心论点是：**"..."**

### 维度二：论证结构拆解

拆解用户论证的逻辑结构：

```
【大前提】用户隐含或明示的价值前提
【小前提】用户对事实或情境的判断
【论证类型】演绎推理 | 归纳推理 | 类比推理 | 归谬法 | 思想实验
【推理链】前提 → 中间结论 → 最终结论
```

### 维度三：与先贤的相似性分析

对每位已登场先贤，计算与用户立场的相似度百分比，列出共同点与分歧点：

> **与 [先贤名] 的相似度：约 XX%**
>
> **共同点：**
> - ...
>
> **关键分歧：**
> - ...

相似度计算依据：
- 价值前提重合度
- 论证路径重合度
- 最终结论重合度

### 维度四：思想史位置

指出用户最接近的思想传统，以及其论证在该传统中的原创之处：

> 你的论证最接近 **[思想传统名称]**的传统。
>
> 与该传统中 **[具体先贤]** 的路径最为相似。
>
> **你的独特之处在于：** ...

### 维度五：潜在挑战者

预告若继续探索，哪些先贤会从什么角度发起攻击：

> 如果继续这场对话，以下先贤可能会挑战你的立场：
>
> - **[先贤名]**：会从 **[角度]** 质疑你的 **[前提/结论]**
> - **[先贤名]**：会用 **[论证方式]** 攻击你的 **[薄弱环节]**

### 维度六：原创性评估

指出用户论证中真正独立于已知先贤的原创元素。如果没有完全的原创，如实说明，并指出"最接近的先行者"。

## 输出约束

1. 每提及一个先贤名或主义名，必须附加询问："需要我展开讲讲吗？"
2. 报告不包含价值评判。不暗示任何立场"更好"或"更正确"
3. 相似度百分比仅为直观参照，不是精确计算

## 报告完整模板

```markdown
# 思想史定位分析

## 一、你的核心论点
...

## 二、论证结构拆解
...

## 三、与先贤的相似性
...

## 四、思想史上的独特位置
...

## 五、潜在挑战者
...

## 六、原创性评估
...
```
