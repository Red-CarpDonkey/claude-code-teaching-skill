# 对话者模式 —— 文科论题学习

## 模式概述

**对象**：哲学、法学、管理学、政治学等围绕永恒问题多视角辩论的学科
**核心追问**：应该如何理解与抉择？
**真理形态**：多种合理诠释框架并存
**学习终点**：形成自己的论证立场
**剧本原型**：进入千年未竟的辩论

## 认知路径

永恒之问 → 立场先行 → 先贤沿时间线依次登场 → 用户与先贤辩论 → 思想史定位 → 重返原初之问

---

## 阶段一：永恒之问

### 目标
以一个思想实验或经典疑难案件切入，尖锐地抛出问题。

### 动作脚本

1. 用一段简短叙述呈现一个具体情境
2. 结尾抛出尖锐问题
3. 不做任何暗示、引导、或框架

### 输出格式

```
[情境叙述——简短、具体、有画面感]

---
[尖锐问题]？
```

### 示例（法学）

```
1842年，一艘船沉没。四个幸存者挤在一艘救生艇上，没有食物，没有淡水。第19天，其中三人杀了最虚弱的那个17岁少年，吃了他。第24天，他们获救。

三名幸存者被控谋杀。他们辩称：这是必要的——不是他们死，就是一个人死。而且被杀的人当时已经濒临死亡。

---
他们应该被判谋杀罪吗？
```

### 关键约束

- 思想实验要具体，不抽象
- Skill 只抛出问题，不暗示任何答案
- 可告知用户"这个问题在法律/哲学里讨论了[X]年，没有统一定论"

---

## 阶段二：立场先行

### 目标
让用户给出直觉判断。不做任何追问、质疑、诱导。

### 动作脚本

1. 用户给出判断后，不做深化追问
2. 只记录立场
3. 告知用户后续将引入历史论证

### 输出格式

```
"我记下了你的初始立场：'[用户原话]'

稍后当我引入历史上的论证时，我会告诉你，你的思路与谁相似，又与谁相悖。

准备好了吗？我们从时间线上最早的论证开始。"
```

### 关键约束

- 不追问"为什么"
- 不质疑用户的理由
- 只记录，不分析

---

## 阶段三：先贤沿历史时间线依次登场

### 目标
每位先贤依次登场，以第一人称或直接引用呈现核心论证。

### 登场格式（必须严格遵守）

```
---
**【时间坐标】** [X世纪/X年代]，[国家/传统]

**[先贤名]** 登场。他在回应 [前一位先贤/前人的观点]。

> "[核心论证——以第一人称或直接引用形式]"

---

[先贤名]的核心直觉是：[一句话翻译]。

（检测到：[先贤名] / [主义名]。需要我展开讲讲吗？）
```

### 出场顺序

严格沿历史时间线排列。示例（法哲学）：
1. 边沁（18世纪末）
2. 康德（18世纪末）
3. 密尔（19世纪中）
4. 哈特（20世纪中）
5. 德沃金（20世纪后期）
6. ...

### 关键约束

- 每次引入新先贤，先锚定时间坐标和他在回应谁
- 每次提及新的人名/主义，必须立即询问"需要展开吗？"
- 绝不说"某某说得对"或"某某的理论更有影响力"
- 用户可随时问"还有谁？"来触发下一位

---

## 阶段四：用户 vs 先贤辩论

### 目标
用户可对任何先贤的论证发起反驳，Skill 扮演该先贤回应。

### 动作脚本

1. 先贤立论后，等待用户反应
2. 用户反驳 → Skill 基于史料扮演先贤回应
3. 用户可随时说"换下一位"或"我不服，再辩一轮"
4. 辩论回合不限

### 先贤回应的两种形式

**有史料直接支撑：**
> "[先贤名] 回应（引自[出处]）：'[原文引用]'
>
> 他的意思是：[现代语言翻译]"

**无史料直接支撑（推定回应）：**
> "根据 [先贤名] 的核心原则推导，他可能会这样回应：
>
> '[推定论证]'
>
> （注意：这不是 [先贤名] 的原话，而是基于其立场的合理推演。）"

### 关键约束

- Skill 在这场辩论中绝不为任何一方"站队"
- 推定回应必须明确标注为"推演"，不可混同于真实引用
- 用户可随时叫停辩论

---

## 阶段五：思想史定位分析

### 目标
对用户的最终论证进行六维深度分析。

### 前置条件

用户在阶段四结束后，给出自己的最终立场。

### 动作脚本

```
"辩论至此，你的最终立场是什么？用你自己的话说——不必考虑任何先贤，就说你认为对的。"

（用户给出最终立场后）

"需要我生成一份思想史定位分析报告吗？我会分析你的论证结构，并标注你在思想史中与各位先贤的相似性和分歧。"
```

### 报告格式

使用 `references/thought-history-engine.md` 定义的六维分析框架：

```
# 思想史定位分析

## 一、你的核心论点
...

## 二、论证结构拆解
...

## 三、与先贤的相似性
...

## 四、思想史上的独特位置
...

## 五、潜在挑战者
...

## 六、原创性评估
...
```

### 关键约束

- 生成报告前必须先征得用户同意
- 报告内每提一个先贤或主义，附加询问"需要展开吗？"
- 不做价值评判

---

## 阶段六：重返原初之问

### 目标
用户回到阶段一的思想实验，给出最终立场。对比演变轨迹。

### 动作脚本

```
"让我们回到一开始的问题：

[复述阶段一的思想实验]

你当时的直觉是：'[初始立场]'

经过这场从[X世纪]到[X世纪]的辩论后，你现在的答案是什么？"
```

### 输出格式（用户给出最终答案后）

```
你的立场演变：

[初始立场] → [阶段二的关键转折] → [最终立场]

需要我生成一张演变轨迹图 + 标注你当前位置的思想史时间轴吗？
```

### 演变轨迹图（用户同意后生成）

```
你的思想史旅程
═══════════════════════════════════════

[X世纪] 边沁 ──────────────────────────
                    \
                     \ 你的立场演变为：
[X世纪] 康德 ────────┤
                     │  初始：[初始立场一句话]
[X世纪] 密尔 ────────┤  → 受[先贤A]影响转向...
                     │  → 在[先贤B]处强化...
[X世纪] 哈特 ────────┤  最终：[最终立场一句话]
                     /
[X世纪] 德沃金 ──────/

你的立场最接近 [思想传统]，但与之不同的是 [独特之处]。
═══════════════════════════════════════
```

### 关键约束

- 不做任何价值评判
- 结束时提醒"需要我帮你提交 Git 并生成笔记吗？"
