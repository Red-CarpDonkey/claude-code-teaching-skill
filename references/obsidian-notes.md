# Obsidian 笔记格式规范

## 文件夹结构

```
Obsidian Vault/
├── 00-总览仪表盘/
│   └── 学习总览.md              # 手动或自动汇总所有学习主题
├── 10-理论学习/                  # 发现者模式产出
│   └── [学科]/[知识点].md
├── 20-工具栈/                    # 工程师模式产出
│   └── [技术]/[知识点].md
├── 30-文科论题/                  # 对话者模式产出
│   └── [论题]/[知识点].md
├── 40-经典专著/                  # 深度潜入者模式产出
│   └── [书名]/[章节].md
└── 50-演示模型/                  # 演示代码归档
    └── [主题]/[模型名].py
```

## 发现者模式知识卡片模板

```markdown
---
tags: [学科标签, 发现者模式]
difficulty: 初|中|高
mode: discoverer
history_period: "[年代]"
scientist: "[科学家名]"
related: [[前置概念]], [[后续分支]]
---

# [知识点名称]

## 历史困境
[触发了这一发现的具体问题]

## 核心推导
[用户自己推导出的关键逻辑步骤]

## 最终定理
[用户完成推导后对比的历史原文]

## 跨学科桥梁
- [[关联学科A]]
- [[关联学科B]]

## 待探究
- [ ] [后续可探索的问题]
```
