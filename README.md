# relive-to-learn

**不是向学习者灌输知识，而是让学习者重演人类知识的发现、发明与对话过程。**

传统教学从结论开始——打开课本，第一章是定义。但知识的诞生，从来不是为了"被学习"，而是为了解决一个当时无法回避的困境。

这个 Claude Code Skill 让学习者回到那个困境的现场，成为必须做出抉择的人。

---

## 四种教学模式

| 模式 | 对象 | 剧本原型 | 核心追问 |
|------|------|----------|----------|
| **发现者** | 理工理论 | 科学家发现自然秘密 | 为什么世界是这样？ |
| **工程师** | 技术工具栈 | 发明家解决工程痛点 | 怎么做能更有效？ |
| **对话者** | 文科论题 | 进入千年未竟的辩论 | 应该如何理解与抉择？ |
| **深度潜入者** | 经典专著 | 进入作者的心灵世界 | 这位作者在说什么？ |

---

## 快速开始

在任意文件夹中输入：

```
/study [你想学什么]
```

Skill 自动诊断学科属性，路由到对应模式。例如：

```
/study 离散数学        → 自动识别为 发现者模式
/study C++             → 自动识别为 工程师模式
/study 法哲学           → 自动识别为 对话者模式
/study 庄子             → 自动识别为 深度潜入者模式
```

你也可以手动指定模式："用工程师模式学图论"。

## 使用方式

### 学习中的交互

CLI 终端只用来**对话**——提问、回答、简短引导。所有教学内容（推导过程、公式、图表、代码、论证）实时写入 Obsidian vault 的板书文件。在 Obsidian 中打开对应文件，即可看到完整渲染的 LaTeX 公式和 mermaid 图表。

### 知识卡片与分支

每当你在学习中做出一个有意义的"分支选择"（选了一条推导路径、选了一个设计方案、选择与某位先贤辩论、选择了一种注疏解释），Skill 会从板书中剪切相关内容，自动生成一张知识卡片。每张卡片带有双向链接，形成你的个人知识网络，可在 Obsidian 图谱中可视化。

### 续接之前的会话

当 token 用完或需要换新会话时：

1. 打开**同一个工作目录**
2. 输入 `/study [同样的主题]`
3. Skill 检测到 `.study/state.json` 存在，自动进入续接模式
4. Skill 会告知你上次学到哪里，板书上还有什么没拆分的笔记

**无需任何手动操作。** 所有学习状态都在文件系统中，不在会话内存中。

### Obsidian Vault 结构

学习过程中会自动创建以下目录和文件：

```
工作目录/
├── 00-总览仪表盘/
│   └── 索引.md                    # 所有学习主题的入口索引
├── 10-理论学习/                   # 发现者模式产出
│   └── [主题名]/
│       ├── [板书]-实时笔记.md      # 当前黑板（未拆分内容）
│       └── [知识点]-[名称].md     # 已拆分的知识卡片
├── 20-工具栈/                     # 工程师模式产出
├── 30-文科论题/                   # 对话者模式产出
├── 40-经典专著/                   # 深度潜入者模式产出
├── 50-演示模型/                   # 演示代码
└── .study/                        # 学习状态（git 忽略）
    ├── state.json                 # 进度追踪
    ├── errors.md                  # 错题集
    └── questions.md               # 疑问日志
```

用 Obsidian 打开工作目录即可看到完整的知识图谱。

## 板书示例

以 `/study 离散数学` 为例，在 Obsidian 中打开 `[板书]-实时笔记.md`，你会看到 mermaid 图、LaTeX 公式、知识树全部正确渲染：

>
> **阶段一：历史电报** — 1736 年，柯尼斯堡。你是欧拉，收到市民来信。
>
> 七座桥连接四个区域：
>
> ~~~mermaid
> graph TB
>     A["北岸"] --- B["克奈普霍夫岛"]
>     A --- B
>     A --- C["洛姆塞岛"]
>     B --- C
>     B --- D["南岸"]
>     B --- D
>     C --- D
> ~~~
>
> **阶段五：推导共创** — 奇数度顶点的判定：
>
> $$
> \text{度数} \equiv 1 \pmod{2} \quad\Rightarrow\quad \text{该顶点只能是起点或终点}
> $$
>
> **定理陈述：** 一张连通图存在一笔画路径，当且仅当奇数度顶点个数为 0 或 2。
>
> **离散数学版图：**
>
> ~~~mermaid
> graph TD
>     DM["离散数学"] --> GT["图论"]
>     DM --> CO["组合数学"]
>     DM --> LO["逻辑与证明"]

>     GT --> GT2["哈密顿路径"]

>     LO --> LO4["数学归纳法"]
> ~~~

> 以上是真实学习记录。CLI 终端只显示简短对话，Obsidian 渲染完整的 mermaid 图、LaTeX 公式和结构化知识。

## 核心理念

1. **起点是困境，不是定义** —— 从一封信、一个悖论、一个工程痛点开始
2. **默认你什么都不知道** —— 遇到术语先翻译再询问
3. **你自己做出抉择** —— Skill 是助产士，不是答案提供者
4. **所有产物先征得同意** —— 演示模型、知识卡片、总结报告，生成前先问你
5. **学习成果固化为知识库** —— Obsidian 双链笔记 + Git 版本控制
