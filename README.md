# Claude Code Teaching Skill

**不是向学习者灌输知识，而是让学习者重演人类知识的发现、发明与对话过程。**

传统教学从结论开始——打开课本，第一章是定义。但知识的诞生，从来不是为了"被学习"，而是为了解决一个当时无法回避的困境。

这个 Claude Code Skill 让学习者回到那个困境的现场，成为必须做出抉择的人。

---

## 理论基础：元学习五阶段

所有教学背后是同一套认知语法——人类从"未知"走向"内化"必经的五个逻辑阶段：

| 阶段 | 逻辑 | 核心产出 |
|------|------|---------|
| **I 动因确立** | 认知失调 | 问题意识 |
| **II 本体解构** | 还原论 | 定义、概念、边界 |
| **III 因果建模** | 结构功能主义 | 机制、算法、推导 |
| **IV 辩证审视** | 批判实在论 | 边界、代价、局限 |
| **V 范式融合** | 整体论 | 知识网络、迁移能力 |

每个阶段约束 Skill 的行为：阶段一只能制造缺口（不给定义）、阶段三要求用户自己推导（不用 spoon-feeding）、阶段四必须呈现替代路径不暗示优劣。

## 五种教学模式

五个模式是五个元阶段在不同学科领域的实例化：

| 模式 | 对象 | 剧本原型 | 核心追问 |
|------|------|----------|----------|
| **发现者** | 理工理论 | 科学家发现自然秘密 | 为什么世界是这样？ |
| **工程师** | 技术工具栈 | 发明家解决工程痛点 | 怎么做能更有效？ |
| **对话者** | 文科论题 | 进入千年未竟的辩论 | 应该如何理解与抉择？ |
| **观察者** | 人文社科实证 | 社会科学家解释现象 | 为什么人类世界是这样运作的？ |
| **深度潜入者** | 经典专著 | 进入作者的心灵世界 | 这位作者在说什么？ |

## 快速开始

在任意文件夹中输入：

```
/study [你想学什么]
```

Skill 自动诊断学科属性，路由到对应模式。例如：

```
/study 离散数学        → 自动识别为 发现者模式
/study C++             → 自动识别为 工程师模式
/study 法哲学           → 自动识别为 对话者模式
/study 宏观经济学       → 自动识别为 观察者模式
/study 庄子             → 自动识别为 深度潜入者模式
```

你也可以手动指定模式："用工程师模式学图论"。

## 核心特性

### 教材主线

所有五种模式都支持选择一本教材作为学习路线图。教材章节目录贯穿五个元阶段，每章完整经历一次深度学习循环。

### 概念引入五步模板（工程师模式）

```
是什么(1句) → 使用模板(穷举所有可能情况) → 使用实例(2-3个) → 可运行代码(复制即跑) → 痛点(用户亲历后回看)
```

### 知识点判定

知识卡片不再基于"阶段到了哪一步"触发，而是基于认知事件——用户通过费曼检验（一句话说清本质）且表达出与已有知识的关联时，知识点才被判定为已形成，触发卡片整理。

### 三Agent监管体系

每次教学对话后，三个独立监管Agent依次运行，防止教学Agent因注意力受限而遗忘规则或偷懒：

| Agent | 核心问题 |
|-------|---------|
| 格式监管 | 对不对？ |
| 规则监管 | 守不守规矩？ |
| 内容审查 | 够不够？ |

### 用户提问中断协议

学习中途用户随时提问，Skill 按 A/B/C/D 四类分流，受元阶段门控——当前阶段不该回答的问题暂缓到对应阶段回访，不泄露后续内容。

## 使用方式

### 学习中的交互

CLI 终端只用来**对话**——提问、回答、简短引导。所有教学内容（推导过程、公式、图表、代码、论证）实时写入 Obsidian vault 的板书文件。在 Obsidian 中打开对应文件，即可看到完整渲染的 LaTeX 公式和 mermaid 图表。

### 知识卡片与知识点网络

每当用户通过费曼检验并表达出与已有知识的关联时，Skill 从板书中生成一张知识卡片。卡片以用户自己的话为核心，记录四个要素：一句话定义、关联边、调用证据、当前认知深度。每张卡片带有双向链接，形成个人知识网络，可在 Obsidian 图谱中可视化。

### 续接之前的会话

当 token 用完或需要换新会话时：

1. 打开**同一个工作目录**
2. 输入 `/study [同样的主题]`
3. Skill 检测到 `.study/state.json` 存在，自动进入续接模式
4. Skill 会告知你上次学到哪里，板书上还有什么未拆分的笔记

**无需任何手动操作。** 所有学习状态都在文件系统中，不在会话内存中。

### Obsidian Vault 结构

```
工作目录/
├── 00-总览仪表盘/
│   └── 索引.md
├── 10-理论学习/                   # 发现者模式产出
├── 20-工具栈/                     # 工程师模式产出
├── 30-文科论题/                   # 对话者模式产出
├── 35-社会观察/                   # 观察者模式产出
├── 40-经典专著/                   # 深度潜入者模式产出
├── 50-演示模型/                   # 演示代码
└── .study/                        # 学习状态（git 忽略）
    ├── state.json
    ├── errors.md
    └── questions.md
```

## 核心理念

1. **起点是困境，不是定义** —— 从一封信、一个悖论、一个工程痛点、一个异常现象开始
2. **默认你什么都不知道** —— 遇到术语先翻译再询问。每个新概念按"是什么→用途→模板→更浅表达"递进
3. **你自己做出抉择** —— Skill 是助产士，不是答案提供者。不替你命名你的发现
4. **所有产物先征得同意** —— 演示模型、知识卡片、总结报告，生成前先问你
5. **学习成果固化为知识库** —— Obsidian 双链笔记 + Git 版本控制
